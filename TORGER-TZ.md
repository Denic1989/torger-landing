# ТЗ: Доработка бота — список задач

## 1. Подтверждение выхода из торгов
**Где:** Чат участника + дубль куратору
**Что сделать:**
- Участник нажимает «Выйти из торгов» → бот в чате участника: «Вы уверены, что хотите выйти? [Да] [Нет]»
- Если подтвердил → куратору в личку приходит сообщение:
  - Текст: «Участник {никнейм_телеграм} хочет выйти. Последняя ставка: {сумма}»
  - Кнопка: [Исключить]
- Если нажал «Нет» → ничего не происходит, участник остаётся в торгах

## 2. Баг: Индикатор опрашиваемого тормозит на одно действие
**Описание:** Индикатор (кто сейчас опрашивается) показывает не того участника, а предыдущего. Отстаёт на один шаг.
**Надо:** Синхронизировать — индикатор должен показывать ТЕКУЩЕГО опрашиваемого, а не предыдущего.

## 3. Баг: История раундов тормозит на одно действие
**Описание:** История раундов (лог/лента торгов) обновляется с задержкой в один раунд. Новый раунд уже идёт, а в истории висит предыдущий.
**Надо:** История должна обновляться синхронно с началом нового раунда.

## 4. Номер участника → анонимный ник
**Где:** На протяжении всего аукциона
**Что сделать:**
- Номер, присвоенный участнику на старте торгов (например, №3), становится его анонимным ником
- Во всех сообщениях для участников и в ленте показывается «Участник №3», а не реальные ФИО/ник
- Действует до конца торгов
- Куратор видит и реальные данные, и анонимный номер

## 5. Тип торгов «Закрытый»
**Где:** Создание/настройка аукциона
**Что сделать:**
- Добавить тип аукциона: «Закрытый»
- При закрытом типе — информация об аукционе публикуется ТОЛЬКО в привязанном канале
- Никакие внешние публикации, рассылки, кросс-посты не делаются

## 6. Обновить инструкцию — добавить контакт
**Что сделать:**
- Отредактировать существующую инструкцию (текст / help / руководство)
- Добавить контактные данные: ФИО, телефон, ссылка на Telegram

## 7. Меню админа
**Где:** В админ-панели бота
**Что сделать:** Добавить раздел со статистикой:
- Количество пользователей
- Количество аукционов в статусе «Черновик»
- Количество аукционов в статусе «Сбор заявок»
- Количество аукционов в статусе «Торги»
- Количество аукционов в статусе «Завершённые»
