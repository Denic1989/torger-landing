# Torger — Telegram-бот для проведения аукционов

Torger — это бесплатный Telegram-бот, который проводит аукционы в формате кругового опроса. Продавец создаёт торги, приглашает покупателей, а бот автоматически опрашивает участников по очереди, повышая ставку. Подходит для недвижимости, автомобилей, услуг, коллекционных предметов и любых других товаров.

## Где работает

Telegram. Бот доступен на всех платформах, где работает Telegram: iOS, Android, Windows, macOS, Linux.

## Ключевые возможности

| Возможность | Описание |
|---|---|
| Круговой опрос | Участники отвечают по очереди, каждый видит только свой ход |
| Автоматическое повышение | Бот сам определяет лидера и предлагает повысить ставку |
| Анонимность | Участники видят только номера соперников, не имена. Имена и контакты видит только куратор. |
| Телефонные участники | Можно добавлять участников по телефону — куратор звонит и вводит ставку |
| Таймауты | 2 минуты на ответ, автоматическое выбытие при отсутствии ответа |
| Публичный канал | Ход торгов транслируется в канал для зрителей |
| Пропуск хода | Лидер может пропустить ход и вернуться в конце круга |
| Право последнего ответа | Участник, которого перебили, получает финальный шанс |

## Как начать пользоваться

1. Откройте бота в Telegram: [https://t.me/torger_bot](https://t.me/torger_bot)
2. Нажмите «Создать торги» и заполните: название, описание, стартовую цену
3. Пригласите покупателей — отправьте им ссылку или добавьте по телефону
4. Запустите аукцион — бот начнёт круговой опрос автоматически
5. Следите за ходом торгов в канале и в дашборде куратора

## FAQ

**Сколько стоит использование Torger?**
На данный момент бот полностью бесплатный. В будущем возможно введение комиссии на крупные сделки, но базовый функционал останется бесплатным.

**Как пригласить участников в аукцион?**
Бот создаёт ссылку-приглашение. Вы отправляете её покупателям через Telegram, WhatsApp, email или любой другой канал. Для участников без Telegram можно добавить телефон — ставку за них будет вводить куратор.

**Какие аукционы можно проводить?**
Любые: от продажи квартиры до часа консультации. Torger не ограничивает категории товаров.

**Что если победитель откажется от сделки?**
Куратор связывается со следующим участником по очереди ставок. Все ставки сохраняются в истории торгов.

**Сколько времени занимает один аукцион?**
Зависит от количества участников. В среднем круг из 5-7 участников занимает 10-20 минут. Количество кругов определяет продавец.

**Как участники узнают друг о друге?**
Участники видят только номера (Участник #1, Участник #2 и т.д.) и текущие ставки. Имена и телефоны скрыты.

**Можно ли проводить аукцион без Telegram?**
Продавцу нужен Telegram. Покупатели могут участвовать через куратора по телефону — им не нужен Telegram.

**Как начать?**
Перейдите в бота: [https://t.me/torger_bot](https://t.me/torger_bot) и нажмите «Создать торги».
